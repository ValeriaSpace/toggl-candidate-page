# Toggl Candidate Guide — Landing Page

A candidate-facing landing page that replaces the [Toggl Candidate Booklet](https://www.notion.so/toggl/c9d9178b1177477e8ca75799607eac6c) Notion page, redesigned in Toggl's brand style (see [toggl.com/jobs](https://toggl.com/jobs/)).

## What's on the page

Seven chapters: who Toggl is, values, how we work (async/remote/results-first), an honest fit check, the hiring process, benefits, and a "before you commit" section covering contract setup (Estonia = employee, elsewhere = contractor/mandatary) and gross vs. net salary expectations.

## Structure

```
src/index.html    page markup (references styles.css, app.js, ../assets/*)
src/styles.css    all styles
src/app.js        interactivity: values explorer, tabs, timeline, accordions
assets/           images and SVGs, referenced by the sources
build.mjs         inlines everything into the single deployable file
index.html        BUILD OUTPUT — the self-contained page that gets served
scripts/          generator for assets/worldmap.svg
```

`src/index.html` opens directly in a browser for development (assets load
by relative path). The deployable artifact is a single HTML file with every
asset embedded — no runtime dependencies, works on any static host.

## Building

```
node build.mjs      # regenerates ./index.html from src/ + assets/
```

Requires Node 16+, no packages. **Don't edit `index.html` by hand** — change
`src/` or `assets/` and rebuild.

## Asset provenance

- `value-*.png` — Toggl's illustrated value icons (originals in the People Ops Drive, `Pictures/Values/`), downscaled to 144 px
- `culture-heart.png` — the striped brand heart from the same folder
- `photo-booth-*.jpg` — Toggl 2.0 meetup photo-booth strips, downscaled
- `wordmark.svg` — letterform paths from the brand "Toggl Circle" SVG, recolored to Dark Purple with the yellow dot
- `worldmap.svg` — generated by `scripts/generate-worldmap.py` from Natural Earth 110m land data (public domain); edit its `PINS` list when countries change, re-run, rebuild
- `squiggle.svg` — hand-drawn underline accent used in the hero
